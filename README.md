# LotoCheck Web

Front-end Vue 3 + Vite para a API Laravel LotoCheck.

## Instalação

```bash
npm install
cp .env.example .env
npm run dev
```

URL local: `http://localhost:5173`

Backend esperado: `https://lotocheck-api.test/api/v1`

Documentação da API: `https://lotocheck-api.test/docs/api`

## Fluxo

- Login/cadastro/visitante/Google em modal
- Poucas telas: Home, Dashboard, Jogos, Resultados e Conferências
- Criação/edição de jogos em modal
- Resultado da conferência em modal
- Suporte a Lotomania com espelho
